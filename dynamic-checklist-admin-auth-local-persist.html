إدارة بنود Dynamic Check‑List

1) منطق الظهور الشرطي
مثال: اجعل Number of devices يظهر فقط إذا كانت إجابة Upgrade Windows 10 to 11 = yes.
2) التكرار حسب حقل عددي
مثال: إذا كان العدد 3 سيتولد 3 حقول مثل: Employee ID 1 / 2 / 3.
3) ربط اختياري بعد الحفظ
مثال مباشر: أنشئ بندًا متكررًا للـ Employee ID واربطه مع windows_upgrades عندما تكون إجابة السؤال الرئيسي Yes.
يمكنك الآن إنشاء بنود شرطية ومتكررة مباشرة من واجهة الإدارة.
