إعداد Firebase وربط Firestore

1) افتح مشروع Firebase الخاص بك وأنشئ Web App. 2) انسخ firebaseConfig وضعه في المتغير داخل الكود. 3) ستُحفظ الفروع في collection اسمها branches والزيارات في siteVisits. 4) ارفع بيانات الفروع الأولية بالضغط على زر رفع بيانات الفروع الأولية مرة واحدة فقط بعد الربط. 
// استبدل القيم التالية من Firebase Project Settings
const firebaseConfig = {
  apiKey: "PUT_YOUR_API_KEY",
  authDomain: "baghethan-ba325.firebaseapp.com",
  projectId: "baghethan-ba325",
  storageBucket: "baghethan-ba325.appspot.com",
  messagingSenderId: "PUT_YOUR_MESSAGING_SENDER_ID",
  appId: "PUT_YOUR_APP_ID"
};
