# إصلاح سريع وآمن — إزالة أيقونة إجازة سنوية و Off فقط أنت محق. التعديل المطلوب كان بسيطًا جدًا: **إزالة الأيقونة فقط** من: 1) الجدول 2) الـ Legend بدون حذف أي شيء آخر. ## 1) داخل الدالة shiftMeta(key) ابحث عن السطور التالية واستبدلها: ```js if(key==='Annual') return {text:t.annualLeave, cls:'Annual', icon:'🌴'}; if(key==='Off') return {text:t.off, cls:'Off', icon:'⛱️'}; ``` بالسطور التالية فقط: ```js if(key==='Annual') return {text:t.annualLeave, cls:'Annual', icon:''}; if(key==='Off') return {text:t.off, cls:'Off', icon:''}; ``` --- ## 2) داخل دالة renderShiftLegend() ابحث عن الجزء التالي داخل metaMap: ```js Annual: { text: t.annualLeave, cls: 'Annual', icon: '🌴' }, Off: { text: t.off, cls: 'Off', icon: '⛱️' } ``` واستبدله فقط بـ: ```js Annual: { text: t.annualLeave, cls: 'Annual', icon: '' }, Off: { text: t.off, cls: 'Off', icon: '' } ``` --- ## 3) حتى لا يبقى فراغ قبل النص داخل الـ Legend ابحث عن هذا السطر: ```js ${meta.icon} ${meta.text} ``` واستبدله بـ: ```js ${meta.icon ? meta.icon + ' ' : ''}${meta.text} ``` --- ## 4) حتى لا يبقى فراغ قبل النص داخل الجدول ابحث عن هذا السطر: ```js ${icon} ${text} ``` واستبدله بـ: ```js ${icon ? icon + ' ' : ''}${text} ``` --- ## النتيجة النهائية - Morning → يبقى مع ☀️ - Night → يبقى مع 🌙 - On Call → يبقى مع 📞 - Work/Coverage → يبقى مع 🏢 - Annual Leave → **بدون أيقونة** - Off → **بدون أيقونة** > هذا هو التعديل الصحيح المطلوب، ولا يمس أي جزء آخر من النظام.
