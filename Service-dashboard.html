IT Service Desk Dashboard

Upload your monthly Excel report (.xlsx) to generate the Performance Dashboard with the same logic as the PowerPoint version.

Expected columns (case-sensitive):
  • • Request ID  — used to detect INC / SR (prefix before the dash)
  • • Status.Name  — Closed / Resolved / Fulfilled / Canceled / On Hold / Open
  • • Department.Name  — used to assign brand group; Subject rules can override the company
  • • Category.Name  — for the categories breakdown
Add a new company or attach a new department to an existing company. Unknown departments will fall under Other until you map them here.
If Subject contains a text like CAMP-HYND-MMP, map it directly to the company, for example Hyundai. Subject company rules are checked before Department.Name mappings.
